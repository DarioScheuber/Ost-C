# AVR C Workspace (OST)

Multi-root VS Code workspace (`C.code-workspace`) with AVR projects for the AT90USB1287
on the OST AVR-USB evaluation board. Each `0x_AVR_Project_*` folder is a copy of
`00_AVR_Project_Template` and builds with its own Makefile.

Datasheet and schematic are in `doc/`. For all C code follow the skill below
(pinout in `.claude/skills/avr-c-coding/hardware.md`).
